# Packet Sniffer

Bu loyiha tarmoqdagi paketlarni kuzatish uchun ishlatiladi. `scapy` kutubxonasidan foydalanadi.

## O'rnatish

1. Python o‘rnatilganligiga ishonch hosil qiling.
2. Kerakli kutubxonalarni o‘rnating:

   ```bash
   pip install -r requirements.txt
   ```

## Ishga tushirish

```bash
python packet_sniffer.py
```

## Eslatma

Bu skript administrator huquqlari bilan ishga tushirilishi kerak.
